# Known limitations and issue reporting

The live issue tracker is
[GitHub Issues](https://github.com/Chap0815/ObsidianTerminal/issues).
An empty tracker is not a claim that the software has no defects.

Important operating and distribution limitations:

- Older private/SSH-only updaters need the migration described in [Updates](UPDATE_SETUP.md).
- Exchange adapter availability is not certification of every account mode or region.
- Stop-loss and trailing decisions are monitored locally; outages can interrupt them.
- Historical research capture gaps cannot be repaired by merely clearing a warning.
- The public package self-test is not the maintainer's full regression suite.
- No configuration, backtest or research result guarantees profitability.

See [Troubleshooting](manual/Troubleshooting.md) for diagnosis and
[Support](SUPPORT.md) for sanitized reports. Report vulnerabilities privately as
described in [SECURITY.md](SECURITY.md).

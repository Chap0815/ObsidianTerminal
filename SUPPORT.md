# Support

Use [Discussions](https://github.com/Chap0815/ObsidianTerminal/discussions) for
installation and usage questions. Use
[Issues](https://github.com/Chap0815/ObsidianTerminal/issues) for reproducible
defects. This community project does not offer a guaranteed response time,
managed trading service or account supervision.

## Before asking

Read [Getting started](manual/Getting-Started.md),
[Troubleshooting](manual/Troubleshooting.md) and the [update guide](UPDATE_SETUP.md).
Include your OS, version/build, strategy, SIM/LIVE mode, steps to reproduce and a
short sanitized error excerpt.

Never attach `.env`, raw runtime folders, API secrets, tokens, private keys or
unredacted account screenshots. Use synthetic examples wherever possible.
Security reports belong in the [private security workflow](SECURITY.md).

## If real positions are affected

Check positions and pending orders directly at your exchange. Do not wait for a
GitHub response to supervise your account. Stopping the program does not by
itself close exposure, and a remote maintainer cannot verify your account from a
screenshot.

Do not delete the database or reset the installation to remove an error.
Preserve evidence privately, avoid duplicate instances, and distinguish
“position closed at the exchange” from “local state successfully reconciled.”
